# Stock Market Quantitative Trading Analysis

台灣股市量化交易策略，input一家公司的股票代碼，會有四個代理開始跑:
第一個是大盤分析師，要去找台灣加權指數的技術指標資料，判斷技術面上是否轉空或是轉多，如發生反轉需要靠你判斷什麼時候才可以買股票，或是給出建議，守住哪條支撐或是跌破哪條壓力應該保守或應該積極低階股票。
第二個是技術分析師，根據股價的五日十日均線判斷股價強不強勢，接著分析支撐壓力區來判斷風險，然後判斷成交量是否有跟上趨勢，最後整理出在技術面上是否可以買進與賣出並與下一個代理討論。
第三個代理是基本面分析師，要告訴其他代理這家公司基本面成長強不強，未來預估獲利多寡，並判斷未來一年本益比換算股價大概會落在哪個區間，本益比請使用三個情境去分析，樂觀、中立與悲觀。
第四個代理是新聞與情緒分析師，會上網找3個與這家公司有關的新聞再找3個台灣股市的新聞再找1個這個產業的新聞最後找兩個國際新聞可能會影響股價的，判斷股市是否過熱，或是公司與產業是否有負面消息會影響股價。
第五個代理是總風控官兼基金經理，要判斷由第一個與第二個與第三個代理提供的數據判斷技術面與基本面是否可以買進，並配上第四個代理給的新聞資料，判斷整體市場風險，與市場是否過熱或過於悲觀，如風險過高可以回答不買股票，並根據前兩位技術分析師給的支撐壓力區來判斷以技術面來看什麼時候才可以買，然後再根據第三位分析師判斷未來預估本益比是否便宜，最後藉由前四位分析師的資料判斷是否可以買股票，並完整說明分析的依據與結論。
